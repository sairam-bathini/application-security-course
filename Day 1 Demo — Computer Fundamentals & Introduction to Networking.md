# Day 1 Demo — Computer Fundamentals & Introduction to Networking

> **Goal:** Understand how a computer works, identify its important components, and get a first look at how computers communicate over a network.

---

## 1. What Is a Computer?

A computer is an electronic device that:

- Accepts data
- Processes data
- Produces information
- Stores data

A simple way to understand a computer is:

```text
Input → Processing → Output
              ↓
           Storage
```

### Example

If we enter:

```text
25 + 75
```

The computer:

```text
Input
  ↓
25 + 75
  ↓
CPU processes the instruction
  ↓
100
  ↓
Output
```

---

# 2. Think About a Real-Life Example

Imagine a teacher receives marks from students.

The teacher:

1. Receives the marks
2. Calculates the total
3. Calculates the average
4. Displays the result
5. Saves the result

A computer performs a similar process.

```text
Data
 ↓
Processing
 ↓
Result
 ↓
Storage
```

This is one of the most important fundamentals of computing.

# 3. Hardware and Software

## Hardware

Hardware means the **physical components of a computer that we can touch**.

Examples:

- Keyboard
- Mouse
- Monitor
- RAM
- SSD/HDD
- Motherboard
- Printer
- Speakers

### Simple definition

> **Hardware = Physical parts of a computer**

---

## Software

Software means the **programs and instructions that tell the computer what to do**.

Examples:

- Windows
- Linux
- Microsoft Word
- Microsoft Excel
- PowerPoint
- Google Chrome
- VLC

### Simple definition

> **Software = Programs and instructions**

---

## Hardware vs Software

```text
Hardware
    ↓
Physical
    ↓
Can be touched

Software
    ↓
Programs
    ↓
Cannot be physically touched
```

### Example

| Example | Type |
|---|---|
| Keyboard | Hardware |
| Mouse | Hardware |
| RAM | Hardware |
| SSD | Hardware |
| Windows | Software |
| Chrome | Software |
| Excel | Software |
| PowerPoint | Software |

---

# 4. Important Computer Components

## CPU

CPU stands for:

**Central Processing Unit**

The CPU executes instructions and performs processing.

A simple analogy:

> CPU is like the brain of the computer.

For example:

```text
10 + 20
   ↓
CPU processes
   ↓
30
```

---

# 5. RAM

RAM stands for:

**Random Access Memory**

RAM is used as temporary working memory while the computer is running.

### Simple analogy

Think of RAM as your **study table**.

When you are studying, you keep the books you are currently using on the table.

Similarly, the computer uses RAM for the programs and data it is currently working with.

```text
RAM
 ↓
Temporary working memory
```

---

# 6. Storage

Storage is used to keep data for long-term use.

Examples:

- SSD
- HDD
- USB drive

Data stored on storage can include:

- Documents
- Photos
- Videos
- Applications
- Projects

### Simple analogy

Think of storage as a **cupboard**.

```text
RAM     → Study table
Storage → Cupboard
```

---

# 7. RAM vs Storage

| RAM | Storage |
|---|---|
| Temporary working memory | Long-term storage |
| Used while programs run | Stores files and applications |
| Usually smaller | Usually larger |
| Data normally disappears when power is lost | Data remains after shutdown |

### Example

If a computer has:

```text
8 GB RAM
512 GB SSD
```

It means:

- **8 GB RAM** → Working memory
- **512 GB SSD** → Long-term storage

# 10. What Happens When We Switch On a Computer?

When we press the power button, several things happen.

A simplified view is:

```text
Power Button
     ↓
Power reaches the computer
     ↓
Hardware initialization
     ↓
BIOS/UEFI
     ↓
Operating System loads
     ↓
Login Screen
     ↓
Desktop
```

### BIOS/UEFI

BIOS/UEFI helps initialize the hardware and start the operating system.

We don't need to go deep into BIOS/UEFI right now.

The important idea is:

> The computer needs to initialize its hardware before the operating system can start working.

---

# 11. Operating System

An **Operating System (OS)** is the main software that manages the computer's hardware and provides a platform for applications.

Examples:

- Windows
- Linux
- macOS
- Android
- iOS

For example:

```text
Hardware
   ↑
Operating System
   ↑
Applications
   ↑
User
```

The operating system acts as an important layer between applications, users, and hardware.

---

# 12. Why Does a Computer Need Electricity?

A computer is an electronic device.

It needs electrical power to operate.

But electrical power can sometimes have problems:

- Power cuts
- Voltage fluctuations
- Power surges
- Electrical faults
- Lightning-related surges

These can interrupt work or potentially damage equipment.

---

# 13. What Is a Power Surge?

A power surge is a sudden increase in electrical voltage.

A simple representation:

```text
Normal
────────────────────

Surge
───────────╱╲───────
           ↑
       High voltage
```

A significant surge can potentially damage electronic equipment.

---

# 14. What Is a Surge Protector?

A surge protector is designed to help protect connected equipment from certain voltage surges.

A simple setup:

```text
Wall Socket
     ↓
Surge Protector
     ↓
Computer
```

> A surge protector is not a guarantee against every type of electrical event.

---

# 15. What Is a UPS?

UPS stands for:

**Uninterruptible Power Supply**

A UPS can provide temporary backup power when the main electricity supply fails.

```text
Normal Power
     ↓
    UPS
     ↓
 Computer
```

When power fails:

```text
Power Failure
     ↓
UPS Battery
     ↓
Computer continues temporarily
```

This gives us time to:

- Save our work
- Close applications
- Shut down the computer safely

---

# 16. What Is Earthing?

Earthing is an important electrical safety measure.

It provides a path for fault current to flow safely into the ground under appropriate fault conditions.

Simple idea:

> Proper electrical installation and earthing help protect people and equipment from electrical faults.

Students should **never open electrical sockets or experiment with electrical wiring**.

---

# 17. Safe Computer Practices

Always remember:

```text
✓ Keep liquids away from computers

✓ Do not use damaged power cables

✓ Do not overload electrical sockets

✓ Keep computer ventilation areas clear

✓ Use appropriate power protection

✓ Keep the computer in a dry environment

✓ Shut down the computer properly

✓ Do not experiment with live electrical wiring
```

---

# 18. Safe Startup

Before starting a computer:

1. Check the power connections.
2. Check that cables are not damaged.
3. Switch on the UPS if provided.
4. Switch on the monitor.
5. Press the computer power button.
6. Wait for the operating system to load.
7. Log in.

---

# 19. Safe Shutdown

When you finish working:

```text
Save your work
     ↓
Close applications
     ↓
Start
     ↓
Power
     ↓
Shut down
```

Avoid switching off the power directly while the computer is running during normal operation.

Why?

Because the computer may be:

- Saving files
- Writing data
- Updating system information
- Closing applications

# 20. Introduction to Networking

Now let's move from **one computer** to **many computers**.

A network allows devices to communicate with each other.

For example:

```text
Computer A
     |
     |
Computer B
     |
     |
Computer C
```

These computers can communicate over a network.

---

# 21. How Does Your Computer Reach a Website?

When you open a website, your computer communicates through a network.

A simplified view:

```text
Your Computer
      ↓
    Router
      ↓
   Internet
      ↓
 Web Server
      ↓
 Website
```

For example, when you open a website:

```text
Computer
   ↓
Request
   ↓
Network
   ↓
Server
   ↓
Response
   ↓
Computer
```

This is the basic idea behind network communication.

---

# 22. What Is an IP Address?

An IP address is a logical address used to identify a device/interface on an IP network.

Example IPv4 address:

```text
192.168.1.10
```

Think of it like an address used for communication on a network.

For example:

```text
Device A
IP: 192.168.1.10

Device B
IP: 192.168.1.20
```

The IP addresses help devices communicate.

---

# 23. Find Your Computer's IP Address

### Windows

Open Command Prompt.

Press:

```text
Windows + R
```

Type:

```text
cmd
```

Press Enter.

Then run:

```text
ipconfig
```

Look for:

```text
IPv4 Address
Default Gateway
Subnet Mask
```

Example:

```text
IPv4 Address : 192.168.1.10
Subnet Mask  : 255.255.255.0
Gateway      : 192.168.1.1
```

> Your actual values may be different.

---

# 24. What Is a Default Gateway?

A default gateway is generally the local router or Layer 3 interface that a device uses to reach destinations outside its local network.

Example:

```text
PC
192.168.1.10
     |
     ↓
Gateway
192.168.1.1
     |
     ↓
Other Networks / Internet
```

Simple idea:

> **Gateway = The device/path used to reach other networks.**

---

# 25. Your First Network Test

We can use the `ping` command to test network connectivity.

Example:

```bash
ping 8.8.8.8
```

If the destination responds, you may see responses such as:

```text
Reply from 8.8.8.8
```

The exact result depends on the network and whether the destination allows ICMP traffic.

---

# 26. What Is Ping?

`ping` is a network diagnostic tool.

It can help us test whether a destination is reachable and measure response time.

Simple idea:

```text
Computer
   |
   |---- "Can you hear me?"
   ↓
Destination
   |
   |---- "Yes!"
   ↓
Computer
```

This is a very basic troubleshooting tool.

---

# 27. Simple Troubleshooting Scenario

Imagine a student says:

> "My computer is connected to Wi-Fi, but the internet is not working."

Instead of randomly changing settings, troubleshoot step by step.

```text
Is Wi-Fi enabled?
        ↓
Is the computer connected?
        ↓
Does it have an IP address?
        ↓
Can it reach the gateway?
        ↓
Can it reach an external destination?
```

Useful commands:

```bash
ipconfig
```

and:

```bash
ping <default-gateway>
```

and, where appropriate:

```bash
ping 8.8.8.8
```

The important skill is:

> **Understand → Test → Identify → Fix**
